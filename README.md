# Memory Match

A browser memory card game. Flip two cards at a time and find every pair in as few moves as you can.

## Features

- Three difficulty levels (6, 8 or 10 pairs)
- Move counter and timer
- Best score saved per level in the browser

## Run it

Open https://ericacirerica.github.io/Memory-Game/ in your browser, or use the Live Server extension in VS Code.

## Files

- `index.html` - page structure
- `style.css` - styling and card flip animation
- `script.js` - game logic
